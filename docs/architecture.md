# Yanny 扬昵 — 小程序短视频平台

## 项目背景

Yanny（扬昵）是一个面向品牌运营方的微信小程序短视频平台。运营主体通过管理后台配置品牌信息、管理视频内容，用户在小程序中浏览短视频（沉浸式上下滑动）、互动（点赞/评论/收藏/分享），管理后台提供埋点数据分析能力。

### 核心场景

| 角色 | 场景 |
|------|------|
| 运营方 | 通过管理后台维护主体信息、小程序账号、视频内容和 CDN 配置 |
| 普通用户 | 在小程序中刷短视频、点赞、评论、收藏、分享 |
| 管理员 | 查看埋点数据（播放量、用户活跃、地域分布等） |

### 与 acop-anylab 的关系

**完全独立**。Yanny 是独立部署的新项目，不复用 acop-anylab 的基础设施（Casdoor、RabbitMQ、task-service 等），仅在部分技术选型上保持一致（Gin + MySQL 8 + Redis）。

### 技术选型明细

| 层 | 技术 | 版本 | 选型理由 |
|----|------|------|----------|
| 小程序框架 | UniApp (Vue 3) | 3.x | 一套代码多端发布（微信/H5），Vue 生态成熟 |
| 管理后台 | Vue 3 + Element Plus | Vue 3.4+ | 中后台通用方案，组件丰富 |
| API 服务 | Go + Gin | 1.21+ | 高性能、轻量，与现有团队技术栈一致 |
| ORM | GORM | 2.x | Go 社区主流 ORM，支持 Migration |
| 数据库 | MySQL | 8.0 | 成熟稳定，支持 JSON 字段、窗口函数 |
| 缓存 | Redis | 7.x | 计数、Session、热点数据缓存 |
| CDN | 七牛云 Kodo | — | 视频/图片上传加速，支持回调通知 |

## API 设计原则

### RESTful 规范

```
GET    /api/v1/{resource}          # 列表（分页）
GET    /api/v1/{resource}/:id      # 详情
POST   /api/v1/{resource}          # 创建
PUT    /api/v1/{resource}/:id      # 全量更新
PATCH  /api/v1/{resource}/:id      # 部分更新
DELETE /api/v1/{resource}/:id      # 软删除
```

### 响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "meta": {
    "page": 1,
    "page_size": 20,
    "total": 100
  }
}
```

### 错误码分段

| 范围 | 含义 |
|------|------|
| 0 | 成功 |
| 10001-19999 | 通用错误（参数校验、未登录、无权限等） |
| 20001-29999 | 主体/小程序管理 |
| 30001-39999 | 视频/分类管理 |
| 40001-49999 | 用户/评论管理 |
| 50001-59999 | CDN/文件上传 |

## 安全设计

| 维度 | 措施 |
|------|------|
| 传输 | 全站 HTTPS |
| 认证 | 微信登录 code2Session → 服务端签发 JWT |
| 敏感数据 | AppSecret、AccessKey、手机号 落库加密（AES-256-GCM） |
| 接口鉴权 | JWT 中间件 + 可选（游客可浏览，互动需登录） |
| SQL 注入 | GORM 参数化查询 |
| 文件上传 | 签名直传七牛云（客户端拿 Token 上传，不经过服务端） |
| 管理后台 | 独立登录体系，bcrypt 密码存储，JWT + 角色鉴权 |
